# waiting-list

わんコメの参加型管理の待機リストを、アイコンと名前で一覧表示するテンプレートです。プレイ中の人は上に色を変えて、待っている人は並んだ順に番号付きで表示します。

設定ページ：https://esusan.github.io/onecomme-waiting-list/

## 特徴

- プレイ中の人（わんコメの各行のスイッチ）は上にまとめて、色を変えて表示します
- 待っている人が0人のときは「参加受付中！」など、好きな文字を表示できます
- 表示しきれない人数は「ほか n人」とまとめます
- 1人分の表示・並べ方・文字の大きさ・寄せる側・色・背景の濃さ・フォント・アイコン・人数を設定ページで選び、URLで指定します
- わんコメの参加型管理の設定にある「OBS用テンプレート」「行／列」「空のときの表記」は使いません。すべて設定ページで決めます

## 導入方法

1. [設定ページ](https://esusan.github.io/onecomme-waiting-list/)の「テンプレートをダウンロード」でzipをダウンロードして展開します
2. `waiting-list` フォルダを `%APPDATA%\onecomme\templates\custom\` に入れます
3. わんコメのテンプレート画面（右上の「…」メニュー →「テンプレート」）に waiting-list が出ていればOKです。出ていなければ、わんコメを起動し直してください
4. わんコメの参加型管理を開いて「有効化」にチェックを入れ、参加ワードを決めます
5. 設定ページで見た目を決めてURLをコピーし、OBSのブラウザソース（「ローカルファイル」はオフ）に貼ります
6. ブラウザソースの大きさを設定ページに出る目安に合わせます
7. 配信の前に、わんコメのコメントテスターで参加ワードを流して、表示を確かめておくのがおすすめです

## URLパラメータ

| 名前 | 既定 | 内容 |
| --- | --- | --- |
| text | {name} | 1人分の表示。`{name}` `{index}` `{count}` `{totalCount}` `{time}` `{comment}` が使えます |
| layout | row | 並べ方（row：縦 / column：横） |
| empty | 参加受付中！ | 待っている人が0人のときの文字（空で何も表示しません） |
| size | 24 | 文字の大きさ(px) |
| side | right | 寄せる側（left / right） |
| color | ffffff | 文字の色（#なしの16進） |
| play | ffd23e | プレイ中の人の色 |
| playlabel | PLAY | プレイ中の人の番号の代わりに出す文字（空で何も出しません） |
| bg | 0 | 背景の黒の濃さ(0〜100)。0は背景なしで、文字の縁取りだけです |
| font | udev | udev / bizud / sans |
| icon | 1 | 0でアイコンを表示しません |
| max | 8 | 表示する人数（プレイ中の人を含む） |
| demo | なし | ダミーで確認します。1（1人ずつ増える）/ all / playing / empty |

`text` は `{name}` だけにするのがおすすめです（番号とPLAYは左の欄に出て、アイコンと名前が縦にそろいます）。`{index}` を入れた場合は左の番号の欄は表示せず、プレイ中の人は `{index}` をまわりの記号（`.` や `No.` など）ごと消して表示します。

ダウンロードしたzipの `config.js` にもその時の設定が入るため、わんコメからドラッグして入れた場合（ローカルファイル指定でURLの設定が付きません）はその設定で表示されます。URLパラメータがあるときはそちらが優先されます。

## 表示されないとき

- 赤い枠で「参加型管理のデータを受け取れません」と表示されるときは、waiting-list フォルダが `%APPDATA%\onecomme\templates\custom\` の外にあります
- 何も表示されないときは、わんコメの参加型管理の「有効化」がオンになっているか確認してください。参加者が0人で `empty` も空のときは、何も表示しないのが正しい動きです
- 見た目が変わらないときは、ブラウザソースが「ローカルファイル」指定になっていないか確認してください。オフにしてURLを貼ってください
- わんコメの参加型管理の「OBS用テンプレート」「行／列」「空のときの表記」を変えても、このテンプレートの表示は変わりません。設定ページで選び直してください
